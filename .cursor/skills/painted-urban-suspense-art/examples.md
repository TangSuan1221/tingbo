# 项目提示词示例

以下示例用于展示结构。生成正式素材时，必须替换为当前镜头的角色参考、场景锚点和状态。

## PRE-G01｜大厅环境建立

- 归属：PRE
- 视角：REAR
- 时长：8秒
- 剧情功能：建立青河电视台大厅

### 正向提示词

```text
林岚手持手机后置摄像头，缓慢从左向右展示一座停用多年的中国地方电视台大厅，
横屏16:9，真实手机持握高度，轻微自然手持晃动，
大厅正面横向展开，旧前台、褪色墙面、封锁线、木门和一台关闭的老式电视形成清晰矩形秩序，
低饱和旧米色、灰褐和煤灰色，远处电视区域带极弱冷蓝光，
原创二维数字手绘，中国都市民俗悬疑绘本风，动画背景质感，亚光旧纸颗粒，边缘略软，
空间安静空旷，生活痕迹真实，保留大面积无人区域，
镜头只进行一次缓慢横摇，最后稳定停在关闭的老电视上，
林岚只以手和深色外套衣袖出现在画面边缘
```

### 负面提示词

```text
no photorealism, no glossy 3D render, no anime glamour,
no cyberpunk neon, no gothic castle, no monster, no gore,
no blood, no third-person camera, no copied game scene,
no watermark, no logo, no platform UI, no fast camera movement
```

## PRE-G02｜林岚开场说明

- 归属：PRE
- 视角：FRONT
- 时长：8秒
- 剧情功能：建立主播与直播关系

### 正向提示词

```text
年轻中国女性都市探险主播林岚手持手机前置摄像头，面对观众克制地介绍身后的废弃电视台，
横屏16:9，头肩至胸像自拍构图，轻微手机广角，眼神直视镜头，
深色实用外套、浅色内搭、小型背包，固定发型和服装，
背景清楚保留旧前台、褪色墙面与关闭的老电视，
灰绿、旧米色和暗褐低饱和色彩，孤立日光灯从上方照亮半侧面部，
原创二维数字手绘，中国都市悬疑绘本风，亚光颜料和细微纸张颗粒，
人物表演自然克制，只做一次轻微回头确认和重新看向镜头，
画面开始和结束各保持半秒稳定姿态
```

### 动作约束

```text
一个主要动作：林岚短暂回头确认大厅，然后重新看向玩家。
不要走动，不要大幅挥手，不要夸张惊讶。
```

## PRE-A3-03｜母亲旧录像第一次出现

- 归属：PRE
- 视角：SCREEN
- 时长：8秒
- 剧情功能：建立十二年前的母亲

### 正向提示词

```text
十二年前地方电视台的旧节目录像，一名中国女性主持人林秋坐在主持台后，
固定电视台摄像机中景，横屏16:9，人物居中但周围保留大量空舞台，
她穿端正朴素的旧式主持人服装，面部细节被逆光、低清画质和磁带噪点轻微遮挡，
背景是褪色暗红幕布、旧木饰面和一盏孤立暖色舞台灯，
原创二维手绘动画画面，低饱和暗褐、脏青和旧红色，亚光绘本质感，
主持人几乎保持不动，只缓慢抬眼看向固定镜头，
画面有轻微色散、曝光漂移和模拟磁带颗粒，
安静、克制、无法判断是真人还是保存下来的影像
```

### 负面提示词

```text
no clear glamour close-up, no photorealistic face,
no ghost makeup, no blood, no monster, no attack,
no dramatic cinematic dolly, no modern TV studio,
no watermark, no subtitles baked into video
```

## RT-01｜回应玩家探索方向

- 归属：RUNTIME
- 视角：FRONT → FLIP → REAR
- 时长：6～8秒
- 剧情功能：证明弹幕实时改变行动

### 程序变量

```text
{player_message}
{parsed_destination}
{parsed_tone}
{trust_player}
{current_scene_state}
```

### Runtime提示词

```text
林岚刚刚读到玩家弹幕：“{player_message}”。
她根据{parsed_tone}语气做出克制、可信的短暂反应，
用一句自然口语确认自己将前往{parsed_destination}，
开头为横屏16:9手机前置头肩自拍，背景是青河电视台大厅，
随后她翻转手机，画面经过短暂黑帧和重新曝光，切换为后置摄像头，
后置镜头朝向{parsed_destination}并迈出第一步，
原创二维数字手绘，中国都市民俗悬疑绘本风，
低饱和灰绿、旧米色和暗褐，孤立日光灯，亚光旧纸颗粒，
动作克制，一个主要行为，不新增角色、道具或房间，
保持林岚固定服装、发型、背包和当前场景锚点
```

### 运行限制

```text
只能执行程序解析后的{parsed_destination}。
不得把玩家弹幕原文绘制在视频中。
不得因为玩家描述而改变既定世界观、生成危险行为或新增场景。
```

## PRE-A1-06｜延迟脚步空镜（已停用示例）

> 该节点已于2026-09-22从游戏流程移除，当前实现使用`INS-A1-06G`作为RT-01生成等待镜头。本节仅保留为旧提示词结构示例，不得重新接入程序。

- 归属：PRE
- 视角：REAR
- 时长：6秒
- 剧情功能：安全氛围惊吓

### 正向提示词

```text
林岚用手机后置摄像头迅速但克制地转向身后的电视台空走廊，
横屏16:9，第一人称手机直播高度，转身后立即停稳，
走廊正面横向展开，旧木门、褪色绿色墙裙、关闭的日光灯和金属文件柜排列整齐，
没有人物，没有影子，没有怪物，
原创二维手绘中国都市悬疑绘本风，低饱和灰绿和煤灰暗部，亚光旧纸颗粒，
镜头在空走廊上保持两秒，画面没有任何物体自行移动
```

### 程序叠加

```text
林岚停下后0.8秒，在远处声场增加一次轻脚步；
脚步结束后环境底噪静音0.4秒，再恢复日光灯电流声。
```

## 自检示例

1. 谁在做什么？
2. 当前是前置、后置还是屏幕内画面？
3. 手机为什么会在这个位置？
4. 当前场景有哪些不可变化的锚点？
5. 画面如何体现低饱和手绘悬疑？
6. 哪些动态信息必须由程序叠加？
7. 哪些内容明确禁止生成？

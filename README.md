# 《停播之后：零号频道》

使用预制视频与MiniMax H3 Runtime视频组合的互动直播影游原型。目前可完整游玩序章、第一幕、第二幕，以及第三幕到`PRE-A3-06`之前的演播厅调查。

## 启动

```powershell
npm install
npm run dev
```

浏览器打开终端显示的本地地址，默认客户端为`http://127.0.0.1:5173`，H3服务端为`http://127.0.0.1:8797`。

## 环境变量

复制`.env.example`为`.env.local`并填写：

```text
LITELLM_KEY=你的服务端密钥
H3_BASE_URL=https://llm-proxy.forgeax.com
H3_MODEL=minimax-h3-max
H3_DURATION=5
H3_SIZE=480p
PORT=8797
```

密钥只由`server/index.mjs`读取，不会进入浏览器Bundle。`.env.local`已加入`.gitignore`。

## 游戏流程

```text
游戏封面（含开发入口）
→ 进入VEIL浏览器里的青河同城论坛
→ 查看停播公告与现场照片
→ 帖子里出现一条来源不明的直播
→ 临时接入并输入本局用户名
→ 序章预制视频
→ 第一幕电视亮起
→ 玩家首次自由弹幕
→ SYS-A1-00等待循环
→ H3生成RT-00
→ 固定异常与调查剧情
→ 玩家选择调查方向
→ INS-A1-06G作为H3生成等待镜头
→ INS-A1-06G完整播放结束且H3已生成后，播放单条10秒RT-01
→ 控制室：抵达控制室门外并进入第二幕PRE
→ 演播厅：在入口发现门缝线缆通向控制室，回头先查控制室并进入第二幕PRE
→ 大厅：使用专属大厅全景首帧检查黑屏电视，确认无异常后前往控制室并进入第二幕PRE
→ 离开：RT-01内真实走出电视台并进入提前结局
→ 无法理解：回到INT-A2-00要求玩家明确方向
→ PRE-A2-02/03/04：控制室与十三号屏幕
→ INT-A2-01：玩家自由提出验证方法
→ H3生成单条8秒RT-02，在同一视频内执行验证并显示结果
→ PRE-A2-05/06：程序把本局用户名跟踪合成到十二年前的观众记录
→ INT-A2-02：玩家解释用户名
→ H3生成单条10秒RT-02B，在同一视频内完成回应与跨屏异常
→ PRE-A2-09/10：前往一号演播厅
→ PRE-A3-01/02：进入演播厅、建立空椅与零号母带
→ PRE-A3-03/04：返看监视器出现林秋，林岚确认母亲身份
→ INT-A3-00 + RT-03：玩家自由回应林秋
→ PRE-A3-05：林秋揭示“上一次回答我的也是你”
→ 确定性抽取一项环境异常：过去弹幕回声或椅子转向
→ INT-A3-01：上滑离开直播，在最近实况、VEIL与电话之间调查
→ 查到0313、听取21:03留言并把证据发回直播，或主动暂缓调查
→ SYS-A3-02/03与事故附件
→ PRE-A3-06：携母带返回控制室，红衣手臂从门内主动关门，林岚大声喝止
→ 第四幕：屏幕林秋要求继续播出，林岚因她与红衣女人长相相同而质疑身份
→ 未来林岚警告被截断，VEIL通知和林岚台词引导玩家按21:03查找残缺留言
→ 玩家把留言发回直播，林岚因此放弃直接播出并改用独立返看机
→ 返看画面同时给出“换人”风险与母亲残缺求救声，玩家在自保和救母之间判断
→ 第五幕：屏幕林秋用私人记忆请求女儿救她，未来林岚警告“重逢就是换人”
→ 熄屏后的林秋CRT余像变成红衣女人轮廓，现实空间不出现鬼影
→ 最终决定：播放母带 / 强制停播
→ 《换人》《停播》两个结局
```

当前可玩实现仍停在`PRE-A3-06`之前；A3-06以后的新生产规格见`停播之后-A3-06后探灵微恐改版.md`。

H3请求使用`first_frame` data URI传入节点指定的连续性参考帧。RT-01固定为单条10秒路线视频，控制室、演播厅和大厅检查分别绑定专属首帧；第三幕RT-03、过去弹幕回声和椅子异常同样绑定PRE尾帧。Runtime的普通话对白、脚步、环境声和空间混响必须由H3与画面同次原生生成；服务端检测不到原生音轨时会将任务标记为失败，不使用独立配音修补Runtime。返回视频会统一转为1280×720、24fps、H.264/AAC后再播放。

玩家用户名限制为2～12个字符，本局开始后保持不变。在`PRE-A2-05+PRE-A2-06`的观众记录镜头中，前端会用宋体、旧墨色、轻微失焦和纸张混合效果跟踪叠加该用户名；后续`INT-A2-02`也会直接引用它。

所有交互正文只描述当下处境，不直接列出可填弹幕。玩家点击“不知道怎么说？”后才会展开可写入语句，点击语句只填入输入框，不会自动发送。

直播开场会保持最多10条高密度观众弹幕，并以约0.9～1.75秒的变化间隔持续向上滚动。首次提示说明“其他观众也察觉了电视异常，但消息刷得太快，林岚尚未注意”，不再把玩家描述为唯一目击者。`PRE-A1-04`会随16秒素材依次收缩为6条、3条、仅玩家1条；在线人数同步降至18、3、1，并逐级叠加扫描噪点、横向信号撕裂、红青错位、不规则亮度闪烁和极短黑帧脉冲。玩家可在直播层直接关注、连续点赞或送出礼物，操作会同步产生计数、飘心、频道提示和礼物弹幕反馈。

当前原型关闭前端Runtime字幕层。Runtime对白只使用H3同次生成的原生同步语音，前端不再后期叠加角色名和对白文本。

故障效果不再只存在于`PRE-A1-04`：其上下相邻的`PRE-A1-02+03`和`PRE-A1-05`各保证出现一次约2～3秒的短闪。单次故障保留原横向波动，并叠加参考录屏式的三次脉冲爆点：短黑闪、亮度跳变、块状切片位移、红青分离和磁带划痕；爆点之间会恢复稳定。异常建立后的部分预制、等待和Runtime视频还会按7～15秒的不固定间隔偶发短闪；用户名记录等需要稳定阅读的镜头被排除。

## 主要文件

- `src/App.tsx`：游戏节点、播放器、弹幕交互和Runtime状态；
- `src/styles.css`：直播间界面与横屏响应式样式；
- `server/index.mjs`：H3请求、轮询、缓存和视频规格化；
- `assets/videos/`：序章、第一幕、等待视频与连续性参考图；
- `停播之后-预制视频拆分清单.md`：完整镜头生产清单。

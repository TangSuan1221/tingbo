# 分镜资产

本目录统一存放后续生成的分镜、镜头参考和审核版本。

当前已确认分镜：

- `act-01/PRE-G00-live-connect-storyboard-approved-v02.jpg`

同一镜头存在多个版本时，仅文件名包含`approved`的版本作为后续视频与相邻分镜参考。

建议结构：

```text
storyboards/
├── act-01/
├── act-02/
├── act-03/
├── act-04/
├── act-05/
└── endings/
```

命名规范：

```text
[镜头ID]-[简短名称]-v01.png
```

例如：

```text
PRE-A1-01-lobby-tv-on-v01.png
RT-03-mother-response-v01.png
RTP-E1-03-mother-returns-v01.png
```

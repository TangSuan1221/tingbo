# 中国都市民俗悬疑绘本风

## 目标

把参考图的高层视觉规律转化为原创美术语言：

- 中国旧式公共建筑与日常生活空间；
- 低饱和手绘质感；
- 平面化、舞台化的空间秩序；
- 克制的人物表演和不安留白；
- 民俗痕迹与现代设施并置；
- 不依赖血腥、怪物和直接暴力的悬疑氛围。

不得复刻参考作品的具体角色、构图、场景、UI、标识或故事元素。

## 使用流程

1. 判断产物类型：角色、场景、道具、分镜、预制视频或Runtime视频。
2. 明确剧情功能：建立空间、推进主线、回应弹幕、提供线索或制造惊吓。
3. 若属于《停播之后》，先读取：
   - `停播之后-零号频道-策划案.md`
   - `停播之后-预制视频拆分清单.md`
   - `assets/characters/lin-lan-approved-character-sheet-v04.jpg`
   - `assets/characters/lin-qiu-approved-character-sheet-v03.jpg`
4. 选择镜头语法：`FRONT`、`REAR`、`FLIP`、`SETDOWN`或`SCREEN`。
5. 按“内容—构图—色彩—光线—材质—动作—限制”顺序写提示词。
6. 检查角色、场景锚点、手机视角和16:9连续性。
7. 输出提示词时同时给出负面约束和连续性锚点。

## 核心视觉语法

### 空间

- 以20世纪末至21世纪初的中国公共建筑为基础：旧电视台、学校、单位走廊、值班室、礼堂、档案室。
- 建筑正面、横向展开，墙面、门窗、柜体形成清晰矩形秩序。
- 空间略显空旷，人物偏小，保留大面积无人物区域。
- 使用真实生活痕迹：墙皮开裂、旧瓷砖、木门、铁柜、暖气片、日光灯、老电视、纸质标语。
- 民俗符号只作少量线索，不堆满符纸、佛像或祭祀用品。

### 画面

- 原创二维数字手绘，带绘本和逐帧动画背景感。
- 形体概括、边缘略软，避免高精度写实照片感。
- 建筑透视稳定，但允许轻微不自然的比例和空旷感。
- 画面层次以大色块、暗部和有限高光区分，不使用复杂镜头炫技。
- 氛围优先于细节数量。

### 色彩

- 主色为褪色灰绿、煤灰、旧米色、脏青和暗褐。
- 局部使用锈红、暗橙或旧灯泡暖色作为危险提示。
- 大部分区域降低饱和度，避免鲜艳纯色和商业插画感。
- 同一场景只设置一个主要色温，异常出现时才允许第二种色温侵入。

### 光线

- 使用孤立日光灯、门缝光、旧电视荧光、窗外阴天光。
- 光源覆盖范围有限，暗部保持有层次而非纯黑。
- 人物可以处在光区边缘，面部不必始终完全照亮。
- 惊吓镜头通过光源熄灭、延迟亮起、颜色偏移或曝光不同步实现。

### 材质

- 亚光、旧纸张、粉尘、轻微胶片颗粒和手绘笔触。
- 墙面与家具允许磨损、霉斑和水渍，但避免过度末日废墟化。
- 旧录像增加低清晰度、磁带噪点、轻微色散和不稳定曝光。
- 不添加现成平台水印、截图边框或来源标识。

### 人物

- 半写实二维叙事立绘，约7.5头身，肩窄、四肢修长，站姿略显拘谨。
- 脸型偏窄长或瘦削，下颌清楚；鼻梁细长，嘴唇薄，避免圆润网红脸。
- 眼睛为写实基础上的细长杏眼，略微放大但不使用日漫大眼；上眼线较重，下眼睑和眼袋以少量阴影概括。
- 使用带自然铅笔摩擦感的深棕或炭黑细轮廓线，以克制平涂和少量手绘明暗塑造体积，不使用赛璐璐渲染。
- 面部体积靠鼻侧、眼窝、下颌和颈部阴影建立，避免水彩晕染和厚涂写实。
- 五官简化但可辨识，眼神明确，表情克制。
- 动作幅度小，以停顿、转头、抬眼、握紧物品和缓慢靠近为主。
- 不使用水彩概念设定、时装插画、夸张动漫表情、Q版比例、3D塑料皮肤或高光偶像妆。

## 《停播之后》镜头规则

- 所有现实直播主画面为横屏16:9手机画面。
- `FRONT`：前置自拍，用于解释、提问、怀疑和回应玩家。
- `REAR`：后置摄像头，用于探索、线索和执行行动。
- `FLIP`：前后摄像头切换，允许短暂黑帧、曝光跳变和对焦。
- `SETDOWN`：手机放在桌面、控制台或地面，仍保持手机镜头逻辑。
- `SCREEN`：屏幕林秋、未来林岚和旧节目只能出现在手机拍到的监视器中。
- `APPARITION`：允许与林秋轮廓相似的“红衣女人”出现在手机、实时监控或黑屏反光中；她不说话、不攻击，站立时抬头并可正对镜头，但整张脸始终被跟随头部的马赛克与高斯模糊覆盖；`PRE-A4-02`允许一次“一帧内直接越过屏框并贴满手机画面”的模糊脸突近景，视觉出现、CRT爆响与林岚尖叫同步，但现实玻璃不破裂、不生成实体穿屏或现实空间冲镜动作；剧情不确认她一定是林秋亡魂。
- A3-06以后惊吓优先采用“具体观察任务吸引注意力 → 屏幕边框/反光/低照度收窄视野 → 假威胁误导 → 边缘或后景兑现 → 人物反应”的节奏；同一显现规律最多连续使用两次。
- 禁止无依据的第三人称摄影机、上帝视角、轨道镜头和传统过肩镜头。

## H3视频规则

- 默认5～8秒单镜头，横屏16:9。
- 每条只包含一个主动作和一个情绪变化。
- 手持晃动低幅，后置镜头优先保证空间可读。
- 前置镜头保持头肩或胸像，背景必须能识别所在场景。
- 角色动作使用“缓慢、克制、停顿后完成”，避免奔跑、搏斗和复杂多人互动。
- 需要画中画时分别生成手机主画面与`SCREEN`素材，再由程序合成。
- 玩家原话、用户名、动态弹幕和结局状态不得烘焙进预制视频。

## 提示词结构

使用以下顺序：

```text
[主体与唯一动作]，
[FRONT/REAR/SETDOWN/SCREEN视角与16:9构图]，
[具体中国旧式空间和固定锚点]，
[低饱和灰绿/旧米色/暗褐色彩关系]，
[孤立日光灯或旧电视光源]，
[原创二维数字手绘、绘本式动画背景、亚光旧纸颗粒]，
[克制悬疑情绪和留白]，
[连续性锚点]，
[禁止项]
```

英文风格核心可使用：

```text
original 2D hand-painted Chinese urban folk suspense,
late-20th-century institutional interior,
muted gray-green and aged beige palette,
semi-realistic narrative character art, slender 7.5-head proportions,
narrow angular faces, natural pencil contour lines, restrained flat colors,
subtle hand-drawn shading, matte paper texture, restrained character acting,
quiet uncanny atmosphere, graphic horizontal composition
```

不得直接使用“复制某游戏画风”“完全一样”“官方截图”等要求。

## 负面约束

默认加入：

```text
no watercolor concept art, no fashion illustration, no photorealism,
no glossy 3D render, no chibi proportions, no round doll-like face,
no anime glamour lighting, no cel shading, no cyberpunk neon, no ornate gothic castle,
no excessive occult symbols, no exposed monster face, no physical lunge at camera, no gore,
no blood, no attack, no watermark, no logo, no copied character,
no third-person cinematic camera for the live feed
```

## 连续性锚点

每组提示词必须重复以下相关信息：

- 以`assets/characters/lin-lan-approved-character-sheet-v04.jpg`作为林岚唯一角色图基准；
- 以`assets/characters/lin-qiu-approved-character-sheet-v03.jpg`作为林秋唯一角色图基准；
- 林岚的固定低马尾、黑灰连帽机能外套、工装裤、背包、摄像机和直播手机；
- 林秋的固定及肩短发、细框眼镜、暗砖红西装、象牙色衬衫和深色百褶裙；
- 当前摄像头为前置还是后置；
- 大厅电视、13号监视器、演播厅空椅子和母带的位置；
- 红衣女人的上一次位置、可见层级（手机/监控/现实）以及脸部马赛克与高斯模糊的强度和稳定度；
- 当前主色温和唯一异常色；
- 椅子朝向、屏幕开关状态和母带是否在手；
- 预制或Runtime归属。

## 质量检查

- [ ] 是原创视觉语言，不可识别地复刻参考作品
- [ ] 横屏16:9且符合手机摄像头逻辑
- [ ] 一个镜头只有一个主要动作
- [ ] 中国旧式公共建筑特征明确
- [ ] 色彩低饱和、光源克制
- [ ] 角色表演安静而非夸张
- [ ] 没有水印、Logo和现成角色
- [ ] 没有血腥、攻击和怪物特写
- [ ] 预制镜头未写入玩家动态内容
- [ ] 与前后镜头的场景锚点一致
